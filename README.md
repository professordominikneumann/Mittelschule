# Mittelschule

Lernspiele für die Mittelschule.

- **Mathe-Werkstatt** (Mathematik, 1. Klasse): natürliche Zahlen, Geometrie, Maßstab, Brüche, Kreis, Dezimalzahlen dividieren – mit Rechenweg bei Fehlern.
- **English Workshop** (Englisch, 1. Klasse, Unit 2 – At the zoo): Vokabeln fangen oder schreiben, Münzen sammeln, Sticker kaufen.

Beide Spiele teilen sich eine Münzkasse; der Sticker-Shop liegt im English Workshop.
